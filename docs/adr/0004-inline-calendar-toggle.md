# ADR-0004: 날짜 선택 UI — 모달 캘린더 대신 상단 인라인 토글

- **Status**: Accepted

## Context

날짜 네비게이션을 일간 스트립만으로는 먼 날짜로 이동하기 불편해서, 월 단위로 조망할 수 있는 캘린더가 필요했다. 처음에는 "전체 캘린더 보기" 버튼을 누르면 뜨는 모달(`MonthCalendar.tsx`)로 구현했다. 이후 실사용 피드백에서, 상단에 "주간보기 / 월간보기"를 상시 토글하는 방식을 사용자가 더 선호했다.

또한 초기 구현에서 주간 헤더와 월간 헤더가 동시에 렌더되어 "이중 헤더"로 보이는 버그가 있었다.

## Decision

- 모달(`MonthCalendar.tsx`)을 삭제하고, `DateNav.tsx` 최상단에 "주간보기 / 월간보기" 토글을 상시 노출한다.
- 토글에 따라 주간 모드(`‹ 날짜 ›` + 7일 스트립)와 월간 모드(`‹ 월 ›` + 요일 헤더 + 6×7 그리드) 중 **하나의 헤더만** 렌더한다.
- 월간 모드에서 날짜를 클릭해도 더 이상 자동으로 주간 모드로 전환되지 않는다 — 이동만 하고 모드는 유지한다(초기엔 자동 전환이었으나 사용자가 불편하다고 해서 제거).

## Consequences

- `MonthCalendar.tsx` 컴포넌트는 저장소에 더 이상 존재하지 않는다.
- 캘린더 상태(주간/월간)가 `DateNav`에 로컬 상태로 존재 — URL에는 반영되지 않는다(새로고침 시 기본 모드로 초기화됨). 필요해지면 별도 RFC로 URL 동기화를 검토한다.
